## 📌 About This Repository

This repository documents a series of practical digital forensics labs completed as part of the **ICDFA (International Cybersecurity and Digital Forensics Academy) Digital Forensics Program**. Each lab simulates a real-world forensic scenario — from acquiring digital evidence to recovering hidden or deleted data — and follows industry-standard methodology for evidence handling, analysis, and reporting.

The goal of this repository is twofold:
- To document my growth and technical competence in digital forensics.
- To serve as a transparent, reproducible record of investigative work for academic, professional, and employer review.

> ⚠️ **Note:** All evidence files, disk images, and datasets used in these labs are either synthetically generated or provided for educational purposes within a controlled lab environment. No real-world case data, personally identifiable information, or third-party evidence is included.

## 🛠️ Tools & Technologies

- **Imaging & Acquisition:** FTK Imager, dd
- **File Carving & Analysis:** The Sleuth Kit (TSK), Autopsy
- **Hex/Binary Analysis:** xxd, hexdump
- **Steganography:** Steghide, stegseek, stegcracker
- **Integrity Verification:** MD5, SHA-1/SHA-256 hashing
- **Environment:** Windows (Git Bash), Kali Linux

---

## 🎯 Skills Demonstrated Across Labs

- Forensically sound acquisition and imaging of digital media
- Maintaining evidence integrity through cryptographic hash verification
- File system analysis and recovery of deleted/hidden data
- Detection and extraction of concealed data using steganographic techniques
- Structured documentation and reporting suitable for legal/investigative review
- Use of industry-standard open-source forensic tooling
